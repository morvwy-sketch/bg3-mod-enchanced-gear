# Enhanced Gear: перевірка в грі

Автоматичні тести (`lua5.4 tests/run.lua`) перевіряють логіку на імітації гри, але не саму гру. Цей список —
що треба пройти в запущеній Baldur's Gate 3, перш ніж вважати функцію робочою. Результат кожного пункту
записуйте в таблицю розділу 2 [MOD_GUIDE.uk.md](MOD_GUIDE.uk.md).

## Підготовка

1. Зберіть мод: `./tools/build.sh` → `dist/EnhancedGear.pak` (або візьміть артефакт CI).
2. Встановіть Script Extender і мод (розділ 3 опису). Увімкніть консоль: `bin/ScriptExtenderSettings.json`
   з `{ "CreateConsole": true }`.
3. У `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Script Extender\EnhancedGear\config.json` залиште
   `"DevTools": true` і за потреби `"Debug": true`.
4. Для перевірок використовуйте **нову** кампанію або окреме збереження.

У консолі не має бути червоних рядків `[EnhancedGear]`. Якщо вони є, скопіюйте їх повністю: це найцінніша інформація.

## 1. Завантаження

| Крок | Очікування |
| --- | --- |
| Запустити гру з модом | У консолі `[EnhancedGear] server loaded (language uk)` і `client loaded (language uk, forge key F7)` (мова — як у грі) |
| Нова гра або завантаження | Рядок `level <назва> started`. Запишіть назви рівнів: таблиця нагород у `Rules.lua` орієнтовна |
| Перший рівень | Головний герой отримує Ковальський набір і 3 брухту, з'являється повідомлення |

## 2. Кузня

| Крок | Очікування |
| --- | --- |
| Використати Ковальський набір поза боєм | Відкривається вікно кузні для цього персонажа, набір не витрачається |
| F7 | Вікно відкривається і закривається. F1–F5, F8–F10 гра обробляє як завжди |
| `!eg_testgear`, `!eg_give all 50`, вкладка «Тест» → «IV (+20)» | Предмети й матеріали з'явилися, технологія IV |
| Список | Згруповано за власниками, спершу екіпіровані, пошук «меч» знаходить «Довгий меч» |
| Покращити довгий меч до +5 | Списано 9 брухту і 220 золота (звичайний меч). Друга копія меча лишилась +0 |
| Наведення на меч | Назва «Довгий меч +5». У другої копії — без «+N» |
| Екіпірувати меч +5 | Атака і шкода +1, зброя магічна (у підказці атаки) |
| Рідкість → Незвичайна, властивість «Полум'я» | Слот предмета світиться зеленим (колір рідкості), удари додають 1 шкоди вогнем |
| Довести меч до +10 і вдарити двічі за хід | Перше влучання за хід — +2 шкоди, друге — без бонусу. Друга рука і дальня зброя рахуються окремо |
| Кольчуга +10 | РЗ +1, здоров'я +5 (у листі персонажа), у «Станах» — «Кування: Нагрудна броня +10» |
| Два персні +5 | Ініціатива +2 (по +1 від кожного) |
| Зняти кольчугу і знову надягти | Бонуси зникають і повертаються рівно один раз (РЗ не росте з кожним перевдяганням) |
| Розібрати неекіпірований предмет | Дві кнопки (розібрати, підтвердити), предмет зник, матеріали додались |
| Переплавка (технологія II+) | 6 брухту + 2 пилу + 100 золота → 1 злиток |
| Почати бій і відкрити кузню | У шапці червоне «Кузнею не можна користуватися в бою», кнопки неактивні |

## 3. Збереження і перенесення

| Крок | Очікування |
| --- | --- |
| Зберегтися, вийти в меню, завантажити | Рівні, назви «+N», кольори рідкості й бонуси на місці, без подвоєння |
| Повний перезапуск гри і завантаження | Те саме |
| Передати кутий предмет супутнику, покласти в скриню, на підлогу, продати і викупити | Стан їде разом із предметом (у вікні той самий рівень) |
| Перейти в інший регіон | Нагорода регіону видається один раз, повторне завантаження не дає її знову |
| `!eg_dump` | Список кутих предметів з «engine colour» і статуси загону |

## 4. Нагороди

| Крок | Очікування |
| --- | --- |
| Убити звичайного ворога, обшукати труп | Іноді в трупі брухт/пил/злиток |
| Убити боса | Повідомлення і 2 пилу, 1 злиток, 1 ядро головному герою |
| Убити призвану істоту або члена загону | Нічого |

## 5. Видалення і діагностика

| Команда | Очікування |
| --- | --- |
| `!eg_cleanup` | Статуси мода зникають, предмети повертають оригінальні назви і кольори |
| `!eg_resync` | Ефекти відновлюються |
| `client`, потім `!eg_rarity` (при відкритій кузні) | Значення кольору, яке бачить клієнт |

## 6. Кооператив

Двоє гравців: кожен відкриває кузню для свого персонажа, операції виконуються по одній, подвійний клік не виконує
операцію двічі, після перепідключення стан той самий. Поки цей пункт не пройдено, кооператив не підтримується офіційно.
